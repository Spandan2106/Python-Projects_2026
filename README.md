# Small Python Projects

This repository contains a collection of simple Python scripts developed for learning and practicing Python programming concepts.

## Projects

### 1. Tic-Tac-Toe Game (`tic.py`)
A command-line implementation of the classic Tic-Tac-Toe game.
- **Features**: Object-Oriented design, Player vs Computer (Random moves).
- **How to play**: Run the script and enter a number (0-8) to place your mark 'X' on the board. The computer plays as 'O'.

### 2. Simple Calculator (`calculator.py`)
A basic calculator that performs fundamental arithmetic operations.
- **Operations**: Addition, Subtraction, Multiplication, Division.
- **Usage**: Enter two numbers and select an operation code (1-4) to see the result.

### 3. Number Swapper (`swap.py`)
A simple utility script to swap two input values.
- **Concept**: Demonstrates Python's ability to swap variables concisely using tuple unpacking.

## How to Run

Ensure you have Python installed on your machine. Open your terminal or command prompt, navigate to the project directory, and run the desired script:

```bash
# Run Tic-Tac-Toe
python tic.py

# Run Calculator
python calculator.py

# Run Number Swapper
python swap.py
```
